# OXIDE: Survival Island 攻略データベース(非公式)

OXIDE: Survival Island v1.17.1179 のアプリ内データから抽出したパラメータを日本語でまとめた、静的HTMLの攻略サイトです。

- `index.html` をブラウザで開くだけで動作します(サーバー不要)。
- 掲載内容: アイテム281件の詳細(レシピ・素材の逆引き・リサイクル・焼成・入手ルート・研究・防護値・内部パラメータ)、銃器/近接/MOD/防具の比較、テックツリー、プレイヤーレベル、モブ、ルートテーブル、資源スポーン、ワールド/イベント設定、スキン928種

## 注意
- 非公式のファンサイトです。開発元とは関係ありません。ゲーム内の画像・データの権利は開発元に帰属します。
- 日本語名は独自訳のため、ゲーム内表記と異なる場合があります。
- サーバー側で値が変更されている可能性があります。

## 再生成
`tools/` に生成スクリプトがあります。日本語名は `tools/ja.py`、パラメータ名は `tools/ja_keys.py` で編集できます。
